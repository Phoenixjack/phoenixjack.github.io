# Privacy and API Data Use

This public site provides project information for Chris McCreary's open-source electronics and KiCad tooling work.

## Site Data Collection

This site does not collect personal information, API credentials, KiCad library files, imported component files, or component metadata.

## Project API Credentials

Manufacturer and distributor API credentials, when configured in related desktop tools, are intended to remain on the user's local machine. Credentials should not be committed to public repositories.

## Manufacturer API Requests

Manufacturer API integrations are intended to request public component information such as manufacturer part numbers, datasheets, descriptions, package details, and ordering metadata. This information may be used locally to improve import previews, naming suggestions, and library maintenance workflows.

## Contact

For project questions, use the relevant GitHub repository linked from the [projects page](projects.md).
