# Chris McCreary's Projects

This site collects public project information for Chris McCreary's open-source electronics, KiCad, and component-library tooling work.

## Current Projects

### KiCad Import Assistant

KiCad Import Assistant is a Python desktop utility for importing vendor-provided KiCad footprints, symbols, and 3D models into local KiCad library structures.

The project emphasizes cautious local workflows: preview discovered files, review planned actions, confirm selected writes, create backups where needed, and avoid unsafe overwrites.

[KiCad Import Assistant project site](https://phoenixjack.github.io/kicad-import-assistant/)

[KiCad Import Assistant GitHub repository](https://github.com/Phoenixjack/kicad-import-assistant)

### KMFDM

KMFDM is a companion KiCad library maintenance project focused on keeping local KiCad library references organized and repairable as library folders evolve.

[KMFDM GitHub repository](https://github.com/Phoenixjack/kmfdm)

## Manufacturer API Use

Some projects may integrate with manufacturer or distributor APIs to retrieve public component metadata, datasheets, package details, and related part information. API credentials, when used, are intended to remain on the user's local machine.
