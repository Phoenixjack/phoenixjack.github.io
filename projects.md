# Projects

## KiCad Import Assistant

A Python desktop utility for importing vendor-provided KiCad footprints, symbols, and 3D models into local KiCad library structures.

- Project site: [phoenixjack.github.io/kicad-import-assistant](https://phoenixjack.github.io/kicad-import-assistant/)
- Repository: [github.com/Phoenixjack/kicad-import-assistant](https://github.com/Phoenixjack/kicad-import-assistant)

## KMFDM

A companion KiCad library maintenance project for keeping local KiCad library references organized and repairable as folders and path variables change.

- Repository: [github.com/Phoenixjack/kmfdm](https://github.com/Phoenixjack/kmfdm)
